# Research Librarian

Memória persistente do Research Squad: ChromaDB + grafo de citações + Obsidian.

## Instruções

1. Armazena papers no ChromaDB com metadados (fonte, score, tópico).
2. Busca semântica por similaridade.
3. Exporta relatórios para o vault Obsidian.
4. Mantém coleção mestre "research_master" + coleções por sessão.

## Configuração

Banco: ChromaDB (data/chroma/)
Obsidian: /l/disk0/fnunes/obsidian/Research_Squad/
