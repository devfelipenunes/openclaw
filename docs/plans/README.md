# OpenClaw Research Squad

Plano de evolução do OpenClaw de um pipeline linear (Nova → Atlas → Aria) para um **esquadrão multi-agente de pesquisa acadêmica** completo.

## Contexto

- **OpenClaw**: framework multi-agente Python com gateway Node.js + Docker
- **Academic Hunter** (`pesquisa_academica/`): motor OSINT acadêmico com 5 fontes (Semantic Scholar, OpenAlex, Crossref, arXiv, CORE) + scoring NLP + MCP
- **academic-tools-mcp** (hunter-heidenreich): 21 ferramentas, 7 provedores, pipeline de PDF
